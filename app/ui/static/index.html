Was erzeugen?

Füllt die Felder; erzeugt wird erst mit dem Knopf unten.

Eine Zeile je Ordner, zwei Leerzeichen je Ebene. „- Titel“ ist eine Datei im Ordner darüber.

Basis (Ist-Stand)

Noch keine Basis. Beispiel laden, ein Ergebnis übernehmen oder JSON einfügen.

Basis als JSON (current_tree)
Gezielte Änderungen

Wirken vor der Freitext-Rückmeldung. Knoten lassen sich auch im Baum rechts über „Ändern …“ wählen.

Gesperrte Äste bleiben unverändert. Auch per „Sperren“ im Baum rechts.

Rahmen

Steuert Sprache, Tiefe und Breite und wird an jedem Knoten als Metadatum gesetzt.

Zusätzlich einbeziehen

Überschriften werden zur Gliederung; Seitenmarken wie <!-- page: 12 --> landen am Knoten.

Weiteres Dokument (optional)

Beide Dokumente werden zu einer Gliederung zusammengeführt.

Eine Zeile je Material: Titel | Schlagworte (Komma) | Kurzbeschreibung. Nur der Titel ist Pflicht.

Werden nur zugeordnet und prägen die Struktur nicht. Gleiches Zeilenformat.

Form (leer = Empfehlung)

Hinweise (Kontext, Ein-/Ausschluss, Ordnung)
Zuordnung von Materialien

Statt Zeilen; Host muss in REF_ALLOWED_HOSTS stehen.

Anmeldung (optional)

Wird nie gespeichert und nur im Aufruf an /v2/topic-tree gesendet.

Anfrage als JSON

Zeigt die Anfrage aus dem Formular. „Bearbeiten“ sendet stattdessen genau diesen Text.

Was möchtest du testen?

Links eine Aufgabe wählen, ein Beispiel laden oder die Felder selbst füllen. Die Aufgabe bestimmt das Gerüst; weitere Eingaben (z. B. Thema + Materialien) kombinierst du unter „Zusätzlich einbeziehen“, fertige Kombinationen stehen in der Beispielauswahl. Gestartet wird erst mit dem Knopf unten links.

0,0 s

Große Bäume mit drei Ebenen brauchen oft 20 bis 50 Sekunden.
